========================================
  CampusFlow · 校园网自动登录
========================================

【这是什么】

一个后台小工具。校园网认证过期或断线时，它自动帮你登录，
不用再打开浏览器输账号密码。

开机自动启动，联网时完全不占资源。


----------------------------------------
【怎么用】四步
----------------------------------------

1. 把 CampusFlow.exe 放到一个固定位置
   例如：D:\CampusFlow\

   ⚠ 不要直接从压缩包里双击运行
   ⚠ 不要放在「下载」「桌面」这类会随手清空的地方

2. 双击打开，在「基础设置」填：
     · 校园网账号 —— 填纯学号，不要自己加 @ 后缀
     · 密码

3. 切到「认证流程」标签，按你办的运营商选一个预设：
     · 本校校园网 · 移动
     · 本校校园网 · 联通
     · 本校校园网 · 电信
     · 本校校园网 · 本地账号

   不确定选哪个就先选「移动」。如果登录报「账号或密码不正确」，
   换一个再试——多半是这里选错了。

4. 回到「基础设置」，点「保存并启用」


========================================
  ⚠⚠  第一次打开会被 Windows 拦住  ⚠⚠
========================================

会弹出「Windows 已保护你的电脑」。

这是因为程序没有花钱买数字签名证书，不是病毒。
Windows 对**所有**未签名的个人程序都会这样提示。

    处理方法：点「更多信息」 → 点「仍要运行」

如果 Windows Defender 拦得更狠、直接删掉了文件，
需要在「Windows 安全中心 → 病毒和威胁防护 → 保护历史记录」
里允许它。

    不放心的可以看源码：
    https://github.com/jone-png/CampusFlow


========================================
  ⚠  必须做的前置设置（不做就用不了）  ⚠
========================================

Windows 必须设成**自动连接**校园网 WiFi。

    设置 → 网络和 Internet → WLAN → 管理已知网络
    → 点你的校园网名字 → 勾选「在信号范围内自动连接」

为什么必须：本工具只负责「向校园网门户提交账号密码」这一步，
它管不了 Windows 去不去连 WiFi。如果 WiFi 是手动连接模式，
开机后压根没连上网，工具自然也没法认证。


----------------------------------------
【怎么确认它在正常工作】
----------------------------------------

打开软件 → 点「运行日志」标签。

成功时能看到类似这样的记录：

    12:34:56  开始执行配方「校园网（移动 @gxyyd）」，共 2 步
    12:34:56  第1步「取门户配置」 返回 2234 字节
    12:34:57  第2步「提交认证」 返回 313 字节
    12:34:58  成功判定 code = 0，期望 0
    12:34:58  配方「校园网（移动 @gxyyd）」认证成功

也可以直接点「测试登录」立刻试一次。


----------------------------------------
【遇到问题】
----------------------------------------

报「账号或密码不正确」
    → 运营商选错了。换一个预设再试
    → 或者密码真的打错了

报「未检测到可用网络」
    → WiFi 没自动连上。做上面那个前置设置

报「已提交，但未确认联网」
    → 认证请求发出去了但结果不明。把「运行日志」发出来看

其他问题
    → 把「运行日志」页的内容截图发出来


----------------------------------------
【关于安全】
----------------------------------------

· 账号密码用 Windows 系统自带的加密功能存在本机
  （只有你自己的 Windows 账户能解密）

· 程序不上传任何数据到任何服务器

· 它只做一件事：向学校自己的认证服务器提交账号密码，
  和你手动打开浏览器登录做的事情完全一样

· 源码公开：https://github.com/jone-png/CampusFlow
